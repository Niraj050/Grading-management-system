# NEB Grading System in C

This project is a console-based C program that simulates the NEB grading system.

## Features
- Admin login to add students
- Store student records in file
- Search student by Reg No and DOB
- Automatic GPA calculation
- Display NEB style marksheet

## Concepts Used
- Structures
- File Handling
- Functions
- Arrays
- GPA logic

## How to Run
gcc neb_grading.c -o neb
./neb
